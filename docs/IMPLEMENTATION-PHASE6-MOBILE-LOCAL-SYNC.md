# StudyOne 개발 6단계 — 모바일 로컬 동기화 실험 (Android/iOS)

> **Canary Draft PR 전용. 새 Stable 버전이나 실사용 자동 동기화가 아닙니다.**

## Android — Debug 전용

- 설정 → **로컬 동기화 실험 · Canary** 화면 추가.
- 127.0.0.1:8765 서버의 기록 수·변경 커서만 읽을 때는 사용자 일정/진도를 전송하지 않음.
- 수동 전송을 눌렀을 때 로컬 저장소를 엄격히 검증하고 서버에 없는 신규 ID만 대상으로 선택.
- 사용자 승인 대화 상자를 거친 뒤 **서버·로컬 데이터를 다시 조회**하여 동일할 때만 전송.
- 최대 50건씩 서버 트랜잭션으로 업로드하며 기존 서버 기록의 자동 변경/삭제는 금지.
- 토큰은 앱 설정/디스크/백업에 저장하지 않으며 UI 닫기 시 제거.
- 기존 Release HTTPS-only 네트워크 정책은 변경 없이 유지. Debug 리소스에서만 localhost HTTP 허용.
- Android 에뮬레이터용 임시 SQLite 테스트 서버에 합성 데이터 2건을 넣고 인증/중복방지 시험 추가.

## iOS — Debug 전용

- 설정 → **로컬 동기화 실험**에서 읽기 및 명시 승인에 따른 신규 ID 업로드 화면 구현.
- URLSession ephemeral 사용, HTTP 리다이렉트 차단, 토큰은 메모리 안의 보안 입력칸에만 일시 보관.
- 로컬 일정 데이터의 불일치·손상이 감지되면 전송 거부.
- 최초 확인 후 업로드 직전 로컬·서버 재검증. 기존 서버/기기 데이터 덮어쓰기 불가.
- Release 빌드에서는 실험용 화면과 통신 코드 제외.
- **주의:** iOS ATS 또는 시뮬레이터 정책으로 현재 개발 빌드의 localhost HTTP 접속이 차단될 수 있음. 빌드 및 실접속 테스트 통과 전까지 네트워크 연결 성공은 주장하지 않음.

## 개발 환경

Android 에뮬레이터는 개발 PC의 로컬 서버를 접근하기 위해 ADB reverse 포트 연결이 필요합니다.

    adb reverse tcp:8765 tcp:8765

서버 실행·토큰 설정 안내: [서버 문서](../server/README.md).

실제 휴대전화의 127.0.0.1 주소는 Windows PC가 아니라 휴대전화 자신입니다. 현재 방식으로 **실제 Android와 iPhone, Windows가 서로 자동 동기화되는 것이 아닙니다**. 이를 우회하려고 보안 검증 없는 LAN HTTP, 포트포워딩, 인터넷 공개를 사용하면 안 됩니다.

## 다음 우선 작업

3. 모바일·Windows 실기기에서 변경 로그 읽기/적용, 반복 동기화, 삭제 전파, 안전한 복구를 통합 검증.
4. ChatGPT 연결에 필요한 읽기/쓰기 권한 및 사용자 승인을 분리.
5. UI/UX 통합과 정식 Beta/Stable 검증/릴리즈.

기존 앱 main, 공개 Beta 릴리즈·배포 파일, Android/iOS 서명/설치 ID 및 사용자 기록은 변경하지 않았습니다. 개인 학습 기록과 API 키를 이 개발 과정에서 업로드하지 않았습니다.
