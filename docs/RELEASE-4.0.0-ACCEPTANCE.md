# StudyOne 4.0.0 통합 릴리스 수용 기준

기준일: 2026-10-25. 이 문서는 **계획 및 출하 차단 조건**이다. 현재 공개 릴리스 또는 실기기 검증 완료를 선언하지 않는다.

## 버전 및 출시 정책

- 새 버전 계열은 `4.0.0`으로 고정. 외부에 공개할 사전 베타는 **`v4.0.0-beta.1` 한 번**. 이후 모든 필수 게이트가 통과한 경우에만 **`v4.0.0` Stable** 신규 태그를 만든다.
- 4.0.0-beta.2/RC/Canary를 반복적으로 공개하는 관성적 개발을 피한다. Beta에서 발견된 버그는 별도 수정 커밋과 QA 결과로 관리한다. 이미 공개된 베타의 서명 파일/태그/아티팩트를 덮어쓰지 않는다.
- Android: `versionCode=40001` (베타), `40002` (Stable) 예정. 기존 `com.studyone.app` **패키지 및 프로덕션 서명 인증서 유지**. Debug 별도 설치본과 실사용 데이터를 혼동하지 않는다.
- iOS: 버전표시 `4.0.0`, 빌드번호 베타 `40001`/Stable `40002` 예정; `com.studyone.ios` 유지. **unsigned IPA는 서명된 실기기 앱 또는 App Store 설치본이 아니다.**
- Windows: 4.0.0 버전 표시·설치/업데이트 정책 및 서명/배포 형태를 검증해 릴리스한다. 기존 무서명 EXE만으로 최종 사용자용 안정판이라고 선언하지 않는다.
- 이 문서를 추가하더라도 현재 Canary 버전 메타데이터는 변경하지 않는다. 실제 후보 코드·버전·서명이 준비됐을 때만 세 플랫폼을 한 커밋에 맞춘다.

## 필수 단계 (반복 없는 단일 검증 패스)

1. **현재 코드를 기준으로 기능 격차를 한 번 분류**한다. 이미 통과한 동일 테스트를 기능 추가 없이 반복 구현하지 않는다.
2. **기존 문제를 우선 수정**한다. 예: 2026-10-25 Phase 33 iOS CI의 앱 내 JSON self-test/시뮬레이터 E2E 실패. 테스트를 제거하거나 조건을 약화해 녹색으로 만들지 않는다.
3. 관련 기능·안전성 수정은 통합 브랜치에서 처리한다. 새로운 기능과 함께 QA 시나리오를 작성한다.
4. 기존 Android/iOS/Windows/Planner/TLS/Recovery CI를 모두 성공시키고, **최종 커밋 기준**으로 결과를 기록한다.
5. 실제 단말·서명·운영 서버·OAuth와 배포 제한을 별도로 검증한다. 에뮬레이터/합성 서버를 실제 운영 E2E로 표기하지 않는다.
6. 전체 체크리스트가 통과했을 때 **베타 한 번**을 신규 GitHub Release로 게시한다. 이후 변경은 베타를 재발행하지 않고 후보 커밋/테스트 기록으로 관리한다.
7. 베타 사용 검증·업그레이드·복원·롤백이 통과하고 차단 이슈가 0개가 된 경우에만 **Stable 4.0.0**을 새 태그/아티팩트로 별도 게시한다.

- [ ] Windows의 설치/데이터 경로/구버전 호환성이 검증되지 않음
- [ ] 동기화의 운영용 HTTPS 인증·실계정 접근제어·기기 오류 복구 미검증

- [ ] 실사용 차단급 결함, 사용자 동의 누락 또는 릴리스 승인 누락

## v4 iOS 4종 통합 복원 개발 변경 (미출시)

Draft PR #60에서는 기존 iOS 내보내기 전용 4종 백업에 대해 **명시 승인형 일괄 복원, 원본 바이트 journal, 중단 시 앱 시작 단계 복구, 4종 순차 실패 원복**, 다른 화면의 오래된 데이터 덮어쓰기 방어를 추가했다. DEBUG iOS Simulator에만 존재하는 합성 E2E가 네 저장 단계의 오류 주입·SHA-256 위조 차단·정상 왕복을 검사하도록 연결됐다.

- **구현 = 출시 검증 완료가 아님**. Swift Release/Debug 컴파일, 실제 iOS Simulator E2E, 원본 부재·중간 프로세스 종료·저장 실패·물리 기기에서의 추가 검증이 필요하다.
- 이 개발로 운영 HTTPS/OAuth/ChatGPT 계정 연결, Android↔iOS↔Windows 자동 동기화가 구현되는 것은 아니다.
- [iOS 4종 복원 구현과 남은 장애 시험](IMPLEMENTATION-V4-IOS-FOURSTORE-RESTORE.md)을 먼저 검토한다.
