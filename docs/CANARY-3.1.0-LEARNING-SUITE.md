# StudyOne 3.1.0-canary.1 — 학습 기능 프리뷰

> **Canary 개발 빌드**. 코드/자동 테스트의 성공과 실기기에서 안전하게 사용할 수 있음을 구분합니다. 새 Stable가 아닙니다.

## 이번 빌드에서 구현한 기능
- Android/iOS/Windows 오답 관리: 과목, 교재·출처, 틀린 문제/개념, 틀린 이유와 정답 근거, 복습일, 재풀이 횟수, 숙달 표시.
- 오답 등록/수정, 오늘까지의 복습 대상 확인, 재풀이 성공 기록, 숙달 여부 변경.
- `studyone-wrong-answers` schema 1(JSON) 수동 내보내기/가져오기. 최대 2MB, 1000항목, 필드/ID/중복 검증.
- 가져오기 시 현재 오답 데이터만 교체하며 이전 원본을 사용자 기기 내부에 별도 백업합니다. 기존 과제·시험·진도·계정·키는 변경하지 않습니다.
- Android/iOS/Windows 영어 쓰기 수행 연습: 정답을 가리고 직접 쓴 문장을 공백 정리 후 대문자·구두점 구분하여 채점. **연습 텍스트는 앱·AI·서버로 영구 저장/전송하지 않음**.
- 버전 표기: Android `3.1.0-canary.1` (versionCode 30101), iOS CFBundleShortVersionString `3.1.0` 및 build 30101, 배포 파일명 `3.1.0-canary.1`.
- 기존 PR #5~#27에 쌓인 일정 상세·진도·일별 5분류·동기화 실험 기능을 기반으로 합니다.

## 이전에 제안했지만 이 빌드에서는 아직 완성하지 않은 기능
- 실제 ChatGPT 앱 계정 연결 및 쓰기 동기화 실사용, 상세정보/오답 서버 동기화 및 자동 충돌 조정.
- 시험별 완전한 기록 아카이빙, AI 사진·PDF 학습지 인식, 집중 타이머, 오프라인 주간 자동 배분 엔진, 학습 통계의 장기 시계열, 3개 플랫폼 모두 동일한 위젯·푸시 알림.
- 위 항목들은 로드맵에 유지하되 **미구현 기능을 출시 기능으로 표시하지 않습니다.**

## 안전 규칙
- `main`과 공개 Beta/Stable 릴리즈는 그대로 유지합니다. Canary는 별도 Draft PR로 검증합니다.
- unsigned iOS IPA는 별도 서명 없이는 설치할 수 없습니다.
- Android CI debug APK는 정식 서명 APK를 덮어쓰는 업데이트가 아닙니다. 기존 설치본을 삭제하지 마세요.
- Windows EXE는 미서명 프리뷰입니다. 실제 사용자 기록이 없는 별도 테스트 계정에서 우선 확인합니다.
- 오답 JSON에는 민감한 학습 내용이 포함될 수 있으므로 공개 업로드를 피하세요.
