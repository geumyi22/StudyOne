# StudyOne v4 P0–P4 연속 개발 — 2026-11-14

상태: 개발 전용 Draft PR #62. 이 문서는 기능별 구현과 검증 범위를 명확히 구분하며 P5 종합 검증·릴리스는 수행하지 않습니다.

## P0 원본 데이터 보호

- 개인 4종 원본(tasks / progress / details / wrongAnswers), 기존 앱 설치, 버전·서명, 공개 태그를 읽거나 수정하지 않습니다.
- 기존 원자적 4종 복구, SHA-256 검증, 동기화 revision CAS/멱등성/삭제 tombstone/오프라인 큐, 승인형 숙제 추가 기능을 보존합니다.
- 새 범용 계획의 미리보기 및 개별 진도 검증은 저장소에 아무것도 쓰지 않습니다.
- 숙제 추가는 Android 기존 원본 스냅샷 재검증·복구본 저장·배치 커밋, iOS 기존 승인형 merge를 재사용합니다.

## P1 모바일 범용 시험지 편집

- Android: 기존 국어 인쇄 18회 템플릿 옆에 독립적인 범용 입력 Dialog 추가. 과목/선택 교재/단원/시험지 종류/총·연속 완료 회차/시작·마감·제외일/일일 최대/복습 출처 입력.
- iOS: 기존 국어 18회 템플릿은 그대로 유지하고 '모든 과목 자유 편집'을 선택했을 때만 일반 편집 필드 표시.
- 양쪽 모두 기존 순수 분배 엔진의 최대치(120일, 12회/일, 240회)를 그대로 적용. 변경된 미리보기의 저장을 차단하고 사용자 확인 전 일정·진도를 변경하지 않음.
- 과목/교재에 속한 개별 진도 UUID와 정확한 회차 이름이 모두 존재할 때만 완료 회차 자동 채우기. 집계 진도로 완료 상태 추정 금지. 원래 진도 스냅샷이 변경되면 추가 취소.
- 기존 18회 UI는 신규 범용 UI로 자동 이전·대체하지 않음.

## P2 내신·5분류 플래너

- 기존 5분류 플래너, 시험범위, 오답, 교재 진도, 과제·수행평가와 '오늘/내일/전체' 흐름을 보존합니다.
- 범용 배분 결과는 '숙제 항목'으로만 추가하며, 완료/진도/시험범위/오답 데이터는 자동 수정하지 않습니다.
- 같은 날짜·과목·제목 또는 합계 인쇄 숙제와의 중복을 거절하며, 다른 기기·화면에서 원본이 바뀌면 전체 등록을 막습니다.
- 범용 교재 등록/데이터 스키마 변경/전 과목 자동 완료 연동은 P5 전 별도 기능 QA 필요.

## P3 기기간 안전 동기화

- 기존 서버 CAS, requestId 멱등성, tombstone, 오프라인 outbox, 계정 격리, 승인형 쓰기 경계를 그대로 사용합니다.
- 실제 인증된 운영 서버 배포 및 3기기 실동기화는 구현 완료 또는 검증 성공으로 표시하지 않습니다.
- 추가된 도구 테스트는 계정별 데이터 격리 및 승인 후 cursor 조회가 오작동하지 않는지 검사합니다.

## P4 ChatGPT MCP 조회 후 확인

- 신규 MCP read-only `studyone_read_plan_status`는 proposalId로 계정 내 대기/승인/거절/만료 상태와 서버 cursor만 조회합니다.
- 실질적 쓰기 권한은 기존 장치의 별도 승인 API에 있고 MCP가 직접 승인·삭제하지 않습니다.
- 사용자는 승인 후 스냅샷/변경 이력 재조회로 실제 작업 반영 여부를 판단할 수 있습니다.
- 운영 OAuth 등록/도메인/계정 로그인/외부 접근·과금은 별도 명시 승인과 운영 설정 전에는 진행하지 않습니다.

## P5 보류

실기기 설치·복구, 실제 사용자 데이터, OS별 접근성·성능, 서명/릴리스 및 운영 보안 종합 검증은 별도 단계로 미완료. 공개 Beta/Stable은 발행하지 않음.
