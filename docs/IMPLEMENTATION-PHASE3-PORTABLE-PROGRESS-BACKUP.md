# StudyOne 개발 3단계 — 진도 전용 JSON 백업·복원

> **개발 브랜치 전용**, 기존 StudyOne Beta 2를 대체하는 Stable 릴리즈가 아닙니다.
> 2단계 교재·진도 관리 PR을 기반으로 한 후속 구현입니다.

## 기능 범위

- Android 플래너: 시스템 파일 선택기를 통해 진도 전용 JSON 내보내기/가져오기.
- iOS 진도 탭: JSON 공유·저장, 파일 가져오기 및 교체 전 확인.
- 진도 전송 파일의 형식 식별자는 studyone-progress, schema=1, items 배열.
- 각 항목은 UUID, 과목·교재·진도 이름, 시험범위 포함 여부, 4가지 상태, revision, updatedAt(ms)을 유지합니다.
- 진도 항목 최대 2000개, 백업 파일 최대 2MB, UUID 중복 및 상태·필수 필드 검증.
- 가져온 내용은 **먼저 전부 검증하고**, 사용자가 현재 진도 교체를 승인한 뒤 저장합니다.
- Android 독립 에뮬레이터 시험: 진도 JSON 왕복 후 모든 필드 일치, 미지원 schema 거부, 중복 ID 거부.
- Android/iOS 상태/키/파일 포맷 일치 검사 추가.
- 기존 학교·시간표·급식·숙제 및 StudyOne schema-1 전체 일정 백업 코드는 수정하지 않았습니다.

## 실제 제한

- **진도 백업은 기존 전체 일정 백업과 별도 파일입니다.** 앱을 제거하거나 기기를 교체할 때는 두 백업이 모두 필요합니다.
- 자동 Android/iOS 동기화나 ChatGPT 연동은 아직 없으며 사용자가 파일을 수동으로 이동해야 합니다.
- 가져오기 동작은 현재 기기의 진도를 **교체**합니다. 기존 진도는 먼저 별도로 백업하세요.
- 보안 정책상 API 키·비밀번호는 백업 파일에 포함하지 않습니다.
- JSON 파일에는 **교재·과목·개인 학습 진도 정보**가 들어 있으므로 공개 저장소나 외부에 업로드하지 마세요.
- 현재 구현은 앱 데이터베이스 트랜잭션/클라우드 동기화/통합 schema-2 마이그레이션이 아닙니다.
- 실기기 파일 선택기 및 백업 복원 E2E는 추가 검증이 필요하며, **Stable 승격 조건은 아직 충족되지 않았습니다.**

## 다음 단계

1. 전체 학교·일정·진도 데이터를 단일 파일로 안전하게 내보내고 기존 schema-1 백업과 호환되도록 하는 통합 스키마 설계·검증.
2. 계정 인증, 데이터 동기화, 수정 이력 서버, 오프라인 큐 및 충돌 관리.
3. 사용자의 StudyOne 실제 데이터 조회·수정·승인 기반 ChatGPT MCP 연결.
4. Android·iOS·Windows UX 통합과 설치형 배포 및 기기별 회귀 검증.
5. Canary/Beta/Stable 채널별 출시 테스트와 실제 Stable 릴리즈.
