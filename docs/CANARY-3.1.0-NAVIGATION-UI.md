# StudyOne 3.1.0-canary.2 — Android UI와 메뉴 버그 수정

## 원인
이전 Android 하단 메뉴는 첫 홈 탭에만 시작할 때 파란 텍스트 색을 고정했습니다. 화면을 전환하는 showTab()에서는 콘텐츠와 제목만 바꾸고 하단 메뉴 색을 갱신하지 않아 홈 표시가 남았습니다. 태블릿 좌측 메뉴에도 활성 탭 식별 표시가 없었습니다.

## 구현
- 홈·시간표·급식·플래너·추천·설정의 6개 24dp 벡터 아이콘.
- currentTab 단일 상태 원본 사용: 탭 클릭마다 아이콘 색, 텍스트 색/굵기, 연한 청색 선택 배경/테두리, 접근성 안내 갱신.
- 스마트폰 하단 메뉴와 태블릿 좌측 메뉴가 동일한 선택 갱신 함수를 사용.
- 홈 요약 카드, 섹션별 파란 표시선, 카드 테두리·그림자 및 상단 툴바 구분.
- 화면 회전으로 Activity 재생성 시 현재 선택 탭 저장과 복구.
- 학교/일정/진도/오답/암기/동기화 원본 스키마는 변경하지 않음.

## 검증
- 아이콘 리소스·선택 상태·양쪽 레이아웃 코드·회전 복원에 대한 Python 계약 검사.
- Android debug APK 빌드/lint/에뮬레이터 실행.
- 에뮬레이터 숨김 진단으로 여섯 탭을 실제 클릭하여 현재 탭, 화면, 활성 상태, 색상, 접근성 문구 일치 검증.
- 물리 기기에서 장시간 조작, 방향 전환 및 사용성 검사는 별도 확인 대상.

## 직접 확인할 사항
1. 홈 진입: 홈 아이콘·텍스트만 강조되는지 확인.
2. 시간표 누르기: 홈 강조가 즉시 사라지고 시간표만 강조되는지 확인.
3. 급식 → 플래너 → 추천 → 설정 → 홈 순서로 이동하며 화면 제목·선택 표시 일치 확인.
4. 플래너 진도/오답/쓰기 수행 영역 경계, 긴 문장 잘림 및 스크롤 상태 확인.
5. 가로 회전 후 선택 탭을 유지하는지 확인.
6. 앱 재실행·일정 체크·시간표 새로고침이 정상인지 확인.

## 출시 안전
- Canary는 기존 Beta/Stable 및 main을 변경하지 않는 Draft 개발 PR.
- Android debug ID: com.studyone.app.canary2. 기존 정상 앱과 별도 저장 데이터 사용.
- 이번 디자인은 Android 중심. iOS와 Windows UI는 동일하게 재설계하지 않음.
- 물리 Android 테스트 전에는 정식 업데이트나 Stable로 표기하지 않음.
