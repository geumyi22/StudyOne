# StudyOne v2.7.0-beta.1 — 통합 베타
Android 17(API 37)용 **시험판, 디버그 서명 APK**입니다.

## 기능
- 시간표·급식 NEIS, 수업·학교 코드 검증, HTTP 500 해결 헤더 유지
- 과제·시험·수행평가·준비물 등록/수정/완료/삭제, D-day, 월간 일정 보기
- 일일 가능 시간 기반 로컬 공부 추천 (외부 AI 호출 없음)
- 사용자 활성화 시 아침/저녁 선택 시각에 대략 알림
- 안드로이드 홈 화면 위젯, 태블릿용 왼쪽 메뉴
- JSON 수동 백업과 가져오기 (NEIS 인증키 제외)

## 미완료
- 생성형 AI 백엔드, 로그인/자동 클라우드 동기화는 미연결입니다.
- NEIS 학사일정 자동 달력 통합과 Kotlin Compose/Room/WorkManager 구조 전환은 미완료입니다.
- 실제 S24U/Android 17에서 기능별 E2E와 시간표·급식 일치는 사용자 기기 테스트가 필요합니다.

## 설치 주의
디버그 APK 서명키는 변경될 수 있어 덮어쓰기가 안 될 수 있습니다. 이전 앱을 삭제하기 전
설정 → 데이터 백업으로 과제를 내보내세요. 앱 삭제 시 기기 데이터는 삭제됩니다.
이 릴리즈는 Google Play용 정식 배포판이 아닙니다.
