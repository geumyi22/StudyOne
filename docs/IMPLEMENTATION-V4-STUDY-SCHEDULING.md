# StudyOne v4 — AI 계획 중복 방지 및 공부 분량 미리보기

기준일: 2026-10-26. 통합 개발 Draft PR #60의 구현 설명. **출시/운영 기능 아님.**

## 1. 중복 AI 제안의 사용자 데이터 보호

- 새 계획 초안에서 동일 (날짜, 역할, 과목, 제목) 항목을 2회 제안하면 **409 DUPLICATE_PLAN_TASK**.
- 앱 승인 시 같은 계정의 기존 미삭제 숙제와 의미 식별자를 비교한다. 기존 숙제가 완료 상태여도 다시 추가하지 않는다.
- 중요도가 달라도, 제목 공백이 다소 달라도 동일 항목으로 판단한다. 날짜가 다른 반복 숙제는 허용한다.
- 확인 및 승인/전체 쓰기는 하나의 SQLite BEGIN IMMEDIATE 트랜잭션에서 실행한다. 하나라도 중복이면 승인 전체를 취소하고 기존 일정·진도 및 cursor를 보존한다.
- AI의 초안 제출은 여전히 실제 일정에 쓰지 않으며, 일반 쓰기 권한 없이 승인할 수 없다.
- 기존 행을 병합·삭제·자동 갱신하지 않는다. 같은 제목으로 서로 다른 숙제를 관리해야 한다면 제목에 구별되는 내용을 입력한다.

## 2. 읽기 전용 시험지·학습지 분배

새 MCP 도구: studyone_preview_paper_schedule. **읽기 전용 미리보기이며 실제 앱 저장 기능이 아니다.**

- startDate, endDate: ISO 날짜, 최대 120일 / maxPerDay: 하루 1~12회
- lanes: 서로 다른 단원/공부 분야. 각 하위 교재는 title, total, 선택적인 completed 개수를 가진다.
- skipDates: 공부하지 않는 날 / firstReview: 처음 개념 복습의 출처(학습지 또는 교재)
- 단원별 번갈아 배정하고 완료한 회차를 제외한다.
- 남은 총량이 남은 작업일 × 하루 상한보다 많으면 **409 SCHEDULE_OVER_CAPACITY**로 전체 거절한다.
- 응답에는 readOnly=true, requiresConfirmation=true를 표기한다. 승인 전 어떤 숙제·진도도 변경되지 않는다.

### 합성 예시

2단원 시험지 종류 3개 × 3회, 3단원 시험지 종류 3개 × 3회, 10월 25일~11월 2일, 하루 2회:

- 10/25: 2-1 소단원 평가 ① + 3-1 소단원 평가 ①, 학습지 복습
- 10/26: 2-2 소단원 평가 ① + 3-2 소단원 평가 ①, 교재 복습
- 10/27: 2단원 대단원 평가 ① + 3단원 대단원 평가 ①, 학습지 복습
- 이후 남은 회차를 반복 배정해 11/2까지 총 18회를 계획한다.

**기존 학습 계획을 자동으로 읽거나 승인·전송하지 않는다.** 개인 규칙은 사용자가 명시적으로 입력하거나, 향후 승인된 실계정 연동으로 전달해야 한다.
