# StudyOne V3 — v3.0.0-beta.1

## 구현 사항
- 실제 OpenAI Responses API 기반 **AI 학습 도우미**: 질문 설명, 복습 퀴즈, 공부 계획 생성 (개인 키 필요)
- Android Keystore AES-GCM으로 저장한 개인 API 키 (사용자 선택/삭제 가능)
- 기본 꺼짐 상태인 과제 공유, 매 AI 요청 전 **공유할 데이터·요금 가능성 확인 및 사용자 동의**
- OpenAI API `store=false`, 길이 제한·출력 상한·타임아웃·사용자 친화적 오류 표시
- 기존 오프라인 공부 추천 및 NEIS, 플래너, 일정, 알림, 위젯, 수동 JSON 백업 유지
- v2.8과 동일한 고정 릴리즈 서명 인증서 및 앱 패키지명으로 앱 삭제 없는 덮어쓰기 업데이트

## 테스트 및 한계
GitHub Actions에서 Gradle build/Lint, APK 서명 지문 및 SHA256, Android API 36 에뮬레이터 설치와 6탭 탐색, **오프라인 AI JSON 응답 파서 fixture 테스트**, 기존 v2.8 서명 APK에서 v3.0 APK로 `adb install -r` 업데이트 테스트를 실행합니다.

**별도의 개인 API 키가 없으므로 실제 OpenAI 유료 API 응답과 개인 휴대폰 S24 Ultra E2E는 자동 검증하지 않았습니다.** AI 응답의 사실관계를 확인해 주세요.

## 설치 방법
이미 v2.8.0-beta.1 **고정 서명 버전**을 설치한 경우, StudyOne 앱 → 설정 → 새 버전 확인 → V3로 업데이트하시면 됩니다. Android 보안 정책에 따라 설치 승인 버튼을 눌러야 합니다. 이전의 임시 디버그 버전은 서명이 달라 덮어쓰기가 되지 않을 수 있습니다.

AI 사용은 선택 사항입니다. AI API 키는 ChatGPT 구독과 별개이고 별도 과금 가능하며, 키를 가진 사용자만 AI 호출을 할 수 있습니다. 미성년자는 보호자와 API 계정/결제 조건을 확인하세요.
