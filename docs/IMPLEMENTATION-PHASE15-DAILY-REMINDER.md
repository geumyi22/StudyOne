# StudyOne 개발 15단계 — 삼성 리마인더형 오늘 할꺼 (Canary)

## 구현
- Android: **오늘 할꺼 · 과목별 리마인더 목록 복사** 추가. 로컬 저장 일정을 읽어 **5개 고정 카테고리**로 정렬하고 `☐ [수학] 중3 내신 종이 숙제`처럼 과목명을 첫머리에 표시합니다.
- iOS: 일정 탭에서 **5개 분류를 항상 구분해 표시**. 각 항목의 원터치 완료/미완료 체크는 기존 로컬 저장소의 `store.toggle`을 이용합니다.
- iOS: **오늘 + 밀린 일정만 표시**를 기본으로 적용하고, 끄면 전체 날짜의 기존 저장 일정을 확인할 수 있습니다. 필터와 과거 분류는 유지합니다.
- 두 플랫폼 복사 정책: 해당 날짜의 과제 + 이전 날짜의 미완료 과제를 포함. 완료한 과거 과제 및 미래 과제는 제외. 미완료 이월 과제는 복사본의 **1. 개별 항목 (전날 못 다)** 에만 배치하며 원래 마감일을 표시합니다. 저장된 분류·날짜·ID는 **변경하지 않습니다**.
- 이전 버전의 과제/수행평가/시험/준비물 등 기존 분류는 삭제하지 않고 **기존 분류 일정**으로 보존합니다.
- 클립보드 복사는 기기 내부에서만 수행. ChatGPT/클라우드에 자동으로 기록·업로드·전송하지 않습니다.

## 테스트/범위
- JVM 독립 스모크로 5개 분류, 과목명 접두어, 이월/미래/완료 제외, 기존 분류 보존과 비수정성을 검증.
- Python으로 Android/iOS UI·복사 계약 확인. 플랫폼별 CI에서 Android lint/APK 및 iOS Swift 빌드 검증.
- 기존 데이터 저장 스키마와 StudyOne 공개 Beta, 기존 main, PR #21 이전 작업 보존.
- 시간 추정은 현재 일별 과제 스키마에 별도 필드가 없어 **임의 생성하지 않습니다**. 예상 시간, 세부 단계·완료 기준 영속 저장, 자동 양방향 동기화, ChatGPT 실제 연결은 다음 개발 범위로 남깁니다.
