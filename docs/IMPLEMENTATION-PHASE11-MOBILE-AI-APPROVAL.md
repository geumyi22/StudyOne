# StudyOne 개발 11단계 — Android·iOS 학습 계획 승인 대기함 (Canary)

## 구현된 기능

- Android 설정의 계정 서버 수동 연결 화면에서 **AI 공부 계획 승인 대기함** 버튼 제공.
- iOS 계정 서버 화면에서 각 승인 대기 계획을 열어 날짜·과목·제목·분류를 확인.
- 두 플랫폼 모두 해당 계획의 상세 항목을 먼저 보여 준 뒤, 사용자의 별도 승인·거부 동작이 있어야만 결정을 전송.
- 서버가 HTTPS에서 계정별로 발급한 읽기·쓰기 토큰만 승인·거부 가능하며 읽기 전용 AI 토큰은 승인 불가.
- 앱의 디스크에 장치 토큰을 저장하지 않으며, 앱의 기존 로컬 숙제/진도 데이터는 결정 과정에서 변경하지 않음.
- 승인 직전에 서버의 초안 목록을 다시 읽어 초안이 바뀌었으면 처리 중지.
- 승인하면 서버에 실제 일정이 추가됩니다. **현재 Android/iOS의 로컬 앱에 해당 일정이 자동 표시되지는 않습니다.** 다른 기기의 변경을 다운로드하는 기능은 다음 단계로 별도 구현·검증이 필요합니다.
- 계정 서버에 주소/인증서/토큰을 직접 설정해야 동작하며, 공개 SaaS나 ChatGPT 계정 연결은 아직 없습니다.

## 테스트

- 기존 Windows AI 승인·거부 UI와 계정별 초안 서버 테스트 기반 유지.
- Android·iOS 신규 코드에 빌드/정적 계약 검사 추가.
- Android 에뮬레이터의 기존 데이터 전송 테스트는 합성 기록만 사용.
- iOS 시뮬레이터에서 실제 HTTPS 서버로 연결하는 전체 E2E는 별도 검증 필요.

## 앞으로 해결할 항목

1. 서버에서 Android/iOS로 신규·기존 기록의 변경 이력과 tombstone을 안전하게 내려받아 로컬에 적용.
2. 각 기기의 미전송 수정·삭제를 추적하는 안전한 오프라인 변경 큐/충돌 해결 UI.
3. 공식 계정 관리, 토큰 저장·회전·폐기, 실제 HTTPS 배포, 백업·복구와 보안 감사.
4. ChatGPT에서 실제 사용자 계정으로 연결하기 위한 OAuth/플러그인 등록과 접근 승인.
5. Android·iOS·Windows 실기기 통합 테스트, 성능·접근성·UI 개선, 코드 서명과 Stable 출시에 필요한 검증.

기존 main, 공개 v3.0.0-beta.2 릴리즈 및 사용자 공부 기록을 변경하지 않고 별도 Draft PR에서 유지합니다.
