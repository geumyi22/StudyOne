# StudyOne v2.8.0-beta.1 — 업데이트 기반 전환

### 새로운 기능
- 공식 GitHub Release에서 새 버전 확인 및 설정 수동 체크
- HTTPS 다운로드 후 SHA-256, 패키지명, 더 높은 versionCode, **현재 앱과 같은 서명 인증서** 검증
- Android 시스템 설치 창으로 기존 앱을 유지하는 업데이트; 사용자 확인 필수
- 기존 NEIS 연동, 학습 플래너, 알림, 위젯 및 JSON 백업 유지

### 기존 임시 디버그 APK에서 전환하는 경우
이전 v2.7.0-beta.1은 GitHub Actions 임시 디버그 키로 서명되었습니다. 이 v2.8.0-beta.1은 영구 서명키로 배포되므로 첫 설치는 서명 불일치로 덮어쓸 수 없을 수 있습니다.
1. 기존 StudyOne에서 과제/일정을 JSON 백업
2. 새 고정 서명 APK 설치 전, 기존 임시 버전 데이터 보존 및 백업 여부 확인
3. 필요하다면 기존 임시 앱을 1회 제거 후 본 APK 설치
4. 이후 릴리즈도 반드시 같은 서명키로 서명하면 데이터 유지 덮어쓰기 가능

### 보안
- 이 릴리즈는 비공개 signing JKS와 GitHub Actions Secrets가 올바르게 설정되었을 때만 빌드됩니다.
- 앱은 설치 전에 공개 SHA-256과 서명 일치를 검증합니다.
- APK 파일이 손상되거나 서명이 다른 경우 설치 흐름을 차단합니다.
- Android 정책에 따라 알 수 없는 앱 설치 허용과 시스템 확인이 필요할 수 있습니다.

### 확인 범위
GitHub Actions 컴파일/서명 검증과 API 36 에뮬레이터 기본 메뉴 실행 테스트를 통과한 빌드만 공개됩니다.
사용자 Samsung S24 Ultra / Android 17의 실제 최종 설치 및 후속 업데이트 테스트는 별도 검증이 필요합니다.
