# StudyOne Windows HTTPS 계정 서버 연결 및 새 항목 수동 병합

**Canary 개발용 기능입니다.** 자동 양방향 동기화가 완료됐거나 Stable 출시된 상태가 아닙니다.

## 실제 구현

- Windows 앱의 동기화 실험 탭에서 서버 URL 변경 지원.
- 로컬 테스트용 주소 127.0.0.1:8765 / localhost:8765에만 HTTP 허용, 그 외 원격 주소는 HTTPS만 허용.
- HTTPS URL은 운영자 승인된 서버/공인 인증서를 사용해야 하며 HTTP로 다운그레이드하거나 인증서 검증을 우회하지 않음.
- 원격 HTTPS 계정 서버에는 v2/snapshot, v2/changes를 이용하고 로컬 기존 서버에는 v1 API 유지.
- 서버의 **신규 일정만 가져오기** 또는 **신규 진도만 가져오기**를 개별 실행 가능.
- 서버에서 현재 PC에 없는 ID만 후보로 계산. 같은 ID가 있고 내용이 같으면 그대로 유지하며, 다르면 충돌로 보고 건너뜀.
- 가져오기 전 사용자 승인, 이후 서버 cursor와 PC의 파일 내용을 다시 확인하여 변동 시 중단.
- 로컬 데이터 파일이 존재하면 원본 JSON을 별도 백업 파일로 복사한 후, 지정된 단일 유형의 JSON만 임시 파일→교체 방식으로 업데이트.
- 원본 로컬 항목 삭제·기존 ID 변경은 절대 자동 실행하지 않음. 서버 삭제 기록도 자동으로 적용하지 않음.
- 신규 일정/진도 백업 전체의 직렬화·중복 ID·입력 검증을 마친 뒤 디스크 저장.
- Windows CI에서 HTTP 원격 거부, HTTPS 허용, 신규 병합, 충돌, 손상된 페이로드 차단을 테스트.

## 지원되지 않는 것

- 자동 백그라운드 반복 동기화 / 로컬 수정분의 기존 ID 서버 업데이트.
- 서버 삭제 이력을 무조건 PC에 적용하는 기능(데이터 손실 위험).
- 동일 ID에 관한 앱 사용자 충돌 선택/재시도 UI.
- Android/iOS의 HTTPS 원격 계정 서버 접속.
- 클라우드 배포, 실제 계정 등록, 운영 인증서, Windows 서명/설치 관리자.
- ChatGPT 연동의 실제 접근 권한·앱 연결.

## 데이터 보존 지침

이 기능을 테스트할 때는 **Windows 기존 StudyOne JSON 일정 및 진도 백업을 먼저 저장**하세요. 서버의 새 데이터 가져오기를 승인하면 해당 유형의 신규 항목만 로컬에 저장됩니다. 업데이트 직전 자동 안전 복사본은 Windows 사용자의 StudyOne 앱 데이터 디렉터리에 생성됩니다. 백업 파일에도 개인 학습 정보가 들어 있으므로 공개하지 마세요.

기존 main, 공개 Beta 버전, 기존 패키지명/릴리즈 파일을 변경하지 않았습니다. 개별 계정의 HTTPS 서버 도메인과 인증 토큰 없이 앱 코드만 설치해도 원격 동기화는 작동하지 않습니다.
