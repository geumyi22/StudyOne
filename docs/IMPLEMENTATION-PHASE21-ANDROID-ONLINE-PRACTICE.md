# Android Canary — 6과목 온라인 내신 문제 빠른 추가

상태: **Android 개발 소스 기능 (배포 버전 아님)**. Android 네이티브 플래너의 **진도** 화면에서 사용자가 직접 시작합니다.

## 동작

1. **플래너 → 진도 → `+ 6과목 온라인 내신 문제 빠른 추가`** 버튼을 누릅니다.
2. 앱은 현재 저장된 진도를 검사해 **국어·사회·역사·과학·영어·수학** 중 `unit="온라인 내신 문제"`가 없는 과목만 제시합니다.
3. 이미 해당 과목/진도명이 있으면 **교재 이름이나 상태가 달라도 건너뜁니다**. 완료·진행 중·미완료·확인 필요 및 기존 ID/수정 이력은 변경하지 않습니다.
4. 추가 예정 과목과 상태를 보여준 뒤 **사용자가 확인할 때만** 새 `미완료`, `시험범위 포함` 항목을 생성합니다. 새 항목의 교재명은 일반적인 `온라인 문제풀이`입니다. 서비스/API 연결은 아닙니다.
5. 저장 직전 기존 진도 원본이 변했는지 재확인합니다. 변했거나 데이터가 손상됐으면 **아무것도 추가하지 않고** 다시 확인하도록 안내합니다.
6. 기존 진도를 앱 내부의 고유한 복구 파일에 먼저 저장한 뒤 새 항목만 추가합니다. 기존 앱 데이터의 4종 통합 백업이나 클라우드 연동을 대신하지는 않습니다.

## 범위와 주의

- 앱/계정에 개인의 특정 60/65개 진도 데이터를 **자동 주입하지 않습니다**. 기존 진도 60개가 정확히 저장되어 있고 사회 온라인 내신 문제가 이미 있다면 새 항목은 5개만 추가됩니다. 없는 경우 결과는 다릅니다.
- 앱 설치 및 버튼 사용 전 **실제 기기에서 4종 통합 백업을 외부 파일로 보존**하는 것이 안전합니다.
- iOS·Windows에는 아직 동일한 새 바로가기 버튼을 추가하지 않았습니다.
- 공식 앱 업데이트 서명/버전/릴리즈 정책은 변경하지 않습니다.
