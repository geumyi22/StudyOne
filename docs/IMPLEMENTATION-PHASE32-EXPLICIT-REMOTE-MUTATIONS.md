# StudyOne Phase 32 — 기존 ID 건별 수정·삭제 승인과 HTTPS CAS 동기화

> **개발 단계(Windows Canary)입니다.** 새 계정·실제 사용자 기록·비밀번호·공개 릴리즈·운영 서버를 건드리지 않습니다. OpenAI API와 유료 인프라를 호출하지 않습니다.

## 구현 내용

- **Windows 동기화 실험 화면에 신규 기능**: 서버 기록 1개를 `task`(일정) 또는 `progress`(진도), 정확한 ID로 지정하고 수정/삭제 중 하나를 선택해 **사용자가 서버와 로컬 내용을 직접 확인하고 승인**합니다.
- 기존 [Phase30] 신규 항목만 올리기와 **명시적으로 다른 동작**입니다. 기존 ID의 변경은 자동·백그라운드로 수행하지 않습니다.
- `/v2/session`으로 HTTPS 계정 서버의 실제 `accountId`, `audience=device`, `scope=read-write`을 확인합니다. 사용자의 raw Bearer 토큰은 저장하지 않습니다.
- `GET /v2/snapshot`으로 실제 서버 `revision`을 확인하고 **`baseRevision=현재 서버 revision`** 하나만 전송합니다. 서버는 트랜잭션 내에서 값이 달라지면 HTTP 409로 전체 요청을 거부합니다.
- **수정**: 같은 ID의 로컬 기록이 있고 그 내용이 서버와 다를 때만 서버 반영을 검토합니다. 서버와 동일하거나 로컬 ID가 없으면 거부합니다.
- **삭제**: 대상 ID가 로컬 PC에 **존재하지 않을 때만** 사용자에게 서버 쪽 삭제를 제안합니다. 로컬에 같은 기록이 남아 있으면 거부합니다. 삭제 요청은 `deleted=true`, `payload=null`인 단일 tombstone입니다.
- 승인 전·후 **같은 서버 계정**, 쓰기 범위, 서버 전역 cursor, 로컬 일정/진도 파일의 정확한 직렬화 바이트, 선택한 ID·기존 revision·변경 내용을 다시 확인합니다.
- 서버 쓰기 전에 **기존 원격 항목의 복구용 원본 JSON**을 `StudyOneCanary/SyncRemoteRecovery/`에 원자적 쓰기로 별도 보관합니다. 복구용 파일 저장 실패 시 서버 요청을 전송하지 않습니다.
- **HTTP 200 응답만으로 성공이라고 표시하지 않습니다.** Phase30의 개별 ACK ID/종류/revision/seq/최종 cursor 검사에 성공해야만 완료 표시됩니다.
- 네트워크 결과가 불명확한 경우 자동 재시도하지 않고 서버 재조회 안내. 409, 잘못된 계정, 읽기 전용 토큰도 자동 재시도·병합하지 않습니다.

## 검증 게이트

- Windows portable .NET 합성 QA: 일정/진도 수정이 실제 서버 revision을 사용함, 같은 내용 수정 거부, 존재하지 않는 ID 거부, PC에 남아 있는 ID 원격 삭제 거부, `payload=null` tombstone, 서버 ACK revision 부정확 시 실패.
- Windows WPF Release 빌드 및 EXE 게시.
- **별도 TLS 서버 E2E**: 계정·토큰 분리, 실제 v2 HTTPS 수정, 다른 기기와 충돌 시 409, 읽기 전용 인증 거부, 삭제 tombstone, 같은 requestId 재전송 멱등성, 삭제 후 재생성 차단.

## 정확한 한계와 후속 작업

1. **Android/iOS의 건별 수정·삭제 UI는 아직 구현되지 않았습니다.** 서버는 수정·삭제 API를 이미 지원합니다.
2. 로컬 기록을 삭제한 것만으로 원격 삭제는 하지 않습니다. 사용자가 ID·종류를 직접 지정하고 승인해야 하며, 원격 삭제가 로컬 장치에 전파되는 것은 아직 지원하지 않습니다.
3. 사용자 계정의 로그인·OAuth 제공자·동의 화면·실제 ChatGPT 플러그인 등록과 공개 HTTPS 호스팅은 별개 작업입니다. MCP JWT 리소스 검증(Phase25) 자체가 로그인 완료를 뜻하지 않습니다.
4. 복구용 원격 JSON에는 **평문 학습 기록·계정 ID·서버 주소**가 포함되어 있으므로 기기 잠금·디스크 암호화와 외부 백업이 필요합니다.
5. **실기기 E2E, 자동 양방향 병합, 기기 간 수정·삭제 UI parity, Stable 릴리즈는 아직 완료로 간주하지 않습니다.**
