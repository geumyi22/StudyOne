# Android daily checklist Canary phase 17

The Android planner now shows five directly tappable categories for today's tasks and unfinished older tasks. The carryover grouping is display-only: IDs, stored categories and due dates are unchanged. Future and previously completed tasks remain available in the expandable complete list. Legacy task classifications remain accessible.

The screen reuses existing local task completion and doesn't upload, import, or fabricate study records. Chat conversation checkmarks do not automatically appear in the app.

Smoke tests cover grouped visibility, carryover, the legacy category, data immutability and clipboard parity. Android build and emulator checks are required before promotion. The public beta, main and on-device records are unchanged.
