# NEIS 학교 검색 문제 진단 (StudyOne 2.0.1-dev.1)

2026-10-10: StudyOne 학교 검색에서 HTTP-500 발생 신고.

## 재현 및 독립 확인
- GET /hub/schoolInfo?Type=json&pIndex=1&pSize=5&SCHUL_NM=서재 : HTTP 200, 3건 (키 없음 샘플 모드)
- GET /hub/schoolInfo?Type=json&pIndex=1&pSize=5&SCHUL_NM=서재중학교 : HTTP 200, 1건
- 같은 검색에 명백히 잘못된 키: HTTP 200, RESULT.ERROR-290

개별 사용자의 NEIS 인증키로 발생한 HTTP-500의 원인은 아직 확인되지 않았습니다.
앱이 개인정보(인증키)를 에러에 출력하거나 로그에 남기면 안 됩니다.

## 코드 변경
- 5xx는 짧은 대기 후 한 번만 재요청, 요청 URL 및 키는 로그/팝업에 노출하지 않음
- 500 오류 시 구조화된 NEIS 메시지가 있으면 추출
- 인증키 포함 학교 검색이 5xx 실패하면 사용자에게 샘플 모드 결과를 선택적으로 표시
- 샘플 결과는 최대 5개이며 전체 학교 검색으로 주장하지 않음
- 실제 시간표·급식 조회는 공식 인증키가 유효할 때만 수행
- 저장된 가짜 데이터로 응답 대체 금지

## 추가 확인 필요
- S24 Ultra / Android 17 / One UI 9에서 재시도
- 정상 발급된 NEIS API 키인지 확인 (키 내용 공유 금지)
- 정확한 학교를 선택하고 학년·반이 일치하는지 확인
- 실제 조회는 학교/기간/급식코드 검증 필요
