# StudyOne 개발 16단계 — Windows 진도/일별 체크리스트 UI 동등성 (Canary)

## 구현
- Windows WPF 일정·진도 테이블의 체크 칸을 실제 클릭 가능한 템플릿으로 교체했습니다. 클릭 시 **기존 로컬 JSON을 읽은 뒤 새 객체로 복제**, 검증/원자적 저장이 성공하면 화면을 갱신합니다. 파일 저장 실패 시 화면을 새로고침하고 원본 오류를 알립니다.
- 일정 체크는 완료/미완료를 반전. 진도 체크는 완료를 해제할 때 **미완료**로 전환하며, '진행 중/확인 필요'는 기존 네 상태 선택 편집 메뉴를 통해 선택할 수 있습니다.
- 이력 필드 `revision` +1 및 `updatedAt` 단조 증가를 유지합니다. 상태 수정을 저장할 때 기존 진도의 ID/교재/시험범위는 보존합니다.
- 2개 복사 버튼: **오늘 할꺼 · 과목명 포함** (5개 고정 분류, 오늘/미완료 이월, 기존 분류 별도 보존) 및 **교재·진도 체크리스트** (과목명 접두어, 완료 상태 및 시험범위 포함 여부).
- 완료 투영 `IsDone`은 **JsonIgnore** 속성으로 보호하여 Android/iOS/Windows 간 기존 진도 JSON 스키마에 영향이 없도록 했습니다.
- 표의 다른 셀은 읽기 전용으로 바꿔 변경 사항이 화면에만 나타나고 저장되지 않는 혼동을 예방했습니다. 명시적인 편집·저장 폼은 그대로 유지합니다.

## 검증
- Windows .NET 8 x64 컴파일과 테스트, EXE Canary 산출물 검증을 GitHub CI에서 수행합니다.
- 순수 C# 포맷 테스트는 5개 분류·과목 접두어·미완료 이월·미래 제외·비수정성 및 `isDone` 직렬화 제외를 확인합니다.
- 사용자 PC 설치나 실데이터 마이그레이션은 수행하지 않습니다. 이 앱은 아직 코드 서명이 없는 개발 프리뷰이며 실기기 E2E 확인 전입니다.
