# StudyOne 개발 14단계 — 진도 직접 체크·과목별 리마인더 복사 (Canary)

## 목적
사용자가 일별 `할꺼` 체크리스트뿐 아니라 **교재·시험범위 진도표**도 앱에서 즉시 선택해 상태를 바꾸기를 요청했습니다. 외부 계정이나 실제 학습 데이터 없이 기존 로컬 저장 형식 위에서 기능을 추가합니다.

## Android / iOS
- 각 진도 항목을 **한 번 눌러 완료/미완료**로 전환. 완료 외의 상태에서 체크하면 완료, 해제하면 미완료로 설정합니다. 상태를 순환시키거나 '진행 중'·'확인 필요'를 실수로 지우지 않도록 원래 상태는 상세 선택 메뉴에서 언제든 지정할 수 있습니다.
- 상태 선택은 **완료 / 진행 중 / 미완료 / 확인 필요** 네 가지를 유지. 각 변경은 기존 저장소의 revision guard 경로를 사용하여 로컬 영구 저장합니다.
- 시험범위 항목의 완료·진행 중·미완료·확인 필요 요약을 표시. Android에는 완료율 막대도 추가합니다. 시험범위 제외 항목은 요약의 분모에 넣지 않습니다.
- **과목명을 앞에 붙인 리마인더용 진도 목록**을 복사하는 버튼 추가. 예: `☑ [과학] 오투 · 7-2 — 완료 (시험범위 포함)`. 순서는 과목→교재→항목, 상태·시험범위 여부를 유지합니다. 복사 동작은 기기의 클립보드에서만 수행합니다. 공유·업로드/동기화가 아닙니다.
- 기존 일별 5개 분류, 과제 체크, 로컬 백업·복원, 사용자 로컬 진도 데이터·ID·revision·저장 스키마·서버 API는 변경하지 않습니다.

## 검증
- Android JDK 독립 formatter 컴파일·스모크: 완료/진행 중 기호, 과목명, 정렬, 빈 목록, 비수정성을 검사.
- Python UX 계약: Android와 iOS 직접 체크, 4단계 상태 메뉴, 별도 저장소/버전 가드를 검사.
- Android CI APK/에뮬레이터, iOS CI Release/Simulator 결과 별도 확인. 서버 및 데이터 이전 테스트에 영향을 주지 않습니다.

## 남은 항목
- **현재 ChatGPT 대화의 체크 상태는 앱과 연동되어 있지 않습니다.** 앱을 새로 설치하더라도 대화의 실제 진도 기록이 자동으로 생성되지 않습니다.
- ChatGPT OAuth 연결, 실서버 배포, 양방향 수정·삭제/충돌 해결·백그라운드 동기화, iOS 실기기 서명·설치, Windows UI 동일 기능과 Stable 릴리즈는 후속 작업입니다.
