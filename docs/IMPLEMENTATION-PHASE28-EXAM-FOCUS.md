# StudyOne Phase 28 — 과목별 시험 준비 대시보드

> 이전 Phase23–27의 백업·OAuth·동기화 기능 반복을 멈추고, **학생이 실제로 매일 보는 학습 화면**을 개선하는 단계입니다. 서버, 운영 계정, 실제 사용자 기록을 변경하지 않습니다.

## 무엇이 바뀌었나

- Android 교재·진도 화면: 시험범위 과목별 `완료/총 항목`, 완료율, 진행 중, 미완료, 확인 필요, 온라인 대기 건수와 **다음에 볼 교재·단원** 표시
- iOS 교재·진도 화면: 과목별 진행 바/완료율/추천할 자료를 읽기 전용 카드로 표시
- Windows 교재·진도 화면: 펼칠 수 있는 과목별 시험 준비 요약과 다음 학습 항목 표시
- 과목의 총 항목·완료율은 **시험범위 포함 = true인 교재·진도만** 기준. 시험범위 제외 기록은 모수에서 제외합니다.
- 기존 과목 우선 배열 `국어·사회·역사·과학·영어·수학`, 기타 과목은 이름순
- 진행 중 → 미완료 → 확인 필요 순서로 남은 **온라인 이외의 자료**를 추천. 해당 과목의 온라인 이외 미완료 항목이 모두 끝나면 `온라인 내신 문제`를 추천할 수 있습니다.
- 온라인 내신은 `unit = "온라인 내신 문제"`라는 **정확한 기존 식별자**로 구분. 텍스트에 추측으로 `시험대비` 등이 포함됐다고 자동 완료 처리하지 않습니다.
- 기존 진도·일정·상태를 변경하지 않는 **읽기 전용 화면**이며 어떤 과목의 시험 대비 자료가 실제로 끝났는지는 사용자가 기록으로 확인해야 합니다.

## 테스트

- Android JVM 합성 fixture: 역사 체크체크 **10장** 진행 중이면 온라인 내신 미완료를 앞서 추천하지 않음, 국어 교재 복습 완료 뒤 온라인 내신을 추천할 수 있음, 과학 시험범위 밖 자료 제외, 원본 상태 불변
- Windows .NET portable 테스트: 동일한 시험범위 3과목 fixture, 완료율/과목 우선순위/온라인 대기/상태 불변
- iOS unsigned IPA + simulator 컴파일: SwiftUI 카드 및 자료 구조 타입 검사
- Android APK 빌드, Lint, 에뮬레이터 실행 CI, Planner Contract Java fixture
- 학교/학원 일정·리마인더, 문제 풀이, 기존 백업 JSON 스키마, OAuth 서버·토큰, 공개 릴리즈는 변경하지 않습니다.

## 남은 사용자 가치 중심 작업

실제 베타 설치·실기기 사용성 QA, 시험 일정/D-day UI, 과목별 시험 범위 편집, 시험 범위와 학습 순서 사용자 지정, 문제·오답 진단, 사용자의 승인형 서버 데이터 연동. 이 문서는 자동 동기화 완료 또는 앱스토어 출시를 주장하지 않습니다.
