# StudyOne 차기 버전 구현 기록 — 5개 학습 분류 기반 (첫 개발 단계)

> 상태: **개발 브랜치/PR 단계, 미출시**. 이 문서는 실제 구현한 범위와 아직 미구현된 범위를 구분합니다. 현재 공개 beta.2에 포함된 기능은 아닙니다.

## 이번 첫 구현

- Android 네이티브(Java) 학습 플래너에 사용자 정의 5개 고정 분류와 **장기 역할 안내** 표시 기능 추가.
- Android 일정 추가·수정에서 5개 분류 중 하나를 선택하고, 플래너 목록에서 분류별로 구분해 표시.
- iOS 네이티브(SwiftUI) 일정 필터 및 편집기에 동일한 5개 분류 선택 기능과 상시 역할 안내 추가.
- 기존 `과제`, `수행평가`, `시험`, `준비물` 항목은 **삭제/자동 변환하지 않고 보존**. 알 수 없는 기존 항목 분류도 수정 시 유지.
- 영구 분류 설명과 날짜별 과제 데이터가 **서로 다른 개념**이라는 기준을 앱 양쪽에 동일하게 적용.
- Android/iOS 분류 동등성, 레거시 유형, JSON schema 1의 불변 여부에 대한 정적 검사 및 JDK 스모크 테스트 구성.
- 기존 JSON backup schema 1, 네이티브 앱 설치 ID, `version.json`, 서명·릴리즈·배포 파일 **변경하지 않음**.

## 검증

- Android: PR에 대해서도 Debug APK 빌드·lint·에뮬레이터 smoke를 실행하도록 CI 트리거 확장.
- iOS: 기존 PR Xcode CI로 unsigned IPA 컴파일·파일 검증.
- 계약: `StudyOne Planner Contract` CI에서 Android/iOS 역할 정의와 기존 백업 형식 유지 확인.
- **Android/iOS 실제 휴대전화 E2E, 앱 간 자동 동기화, 신규 UI 접근성·성능 점검은 아직 미실시**.

## 후속 구현 범위 (이 PR에 포함되지 않음)

1. 기존 앱의 로컬 task 저장·양 플랫폼 백업 schema 1 구조 감사 및 회귀 시험.
2. 과목별 시험범위·교재·진도·오답 상태(완료·진행 중·미완료)의 독립된 데이터 모델과 안전한 이관.
3. 하루별 상세 계획의 중복 방지, 사용자가 직접 수정한 이력, 이월 및 날짜별 정책.
4. 오프라인 우선 동기화 DB/API, 인증·인가·충돌 해결, 변경사항 조회 커서.
5. ChatGPT MCP 연결의 실제 읽기·쓰기 기능과 승인/최신 상태 재조회.
6. Windows 설치형 앱, UI/UX 통합 및 성능 최적화.
7. Canary → Beta → Stable 단계 검증 및 플랫폼별 배포.

현재 v3.0.0-beta.2의 설치 파일·릴리즈를 수정하지 않았습니다. 이 개발 브랜치를 Stable이라 부르지 않습니다.
