# StudyOne Android 3.1.0-canary.3 — Planner Hub

## 개선 배경
기존 플래너 한 화면에 오답·쓰기·진도·백업·복사·전체 일정과 5개 분류를 모두 세로로 나열해 핵심 공부 일정까지 스크롤이 지나치게 길었습니다. 마감이 내일인 숙제는 오늘 할꺼에는 없고 홈 추천·추천 순서·전체/달력에만 나타나 혼란스러웠습니다.

## 개편
- 플래너 상단 좌우 스크롤 탭: **오늘 / 내일 / 전체 / 진도 / 오답 / 쓰기 / 관리** (7개).
- 오늘: 기존 오늘 일정·이전 날짜 미완료 항목의 5개 분류를 표시하되 빈 분류는 접습니다. **내일 마감 숙제의 미리 하기 영역**을 바로 보여줍니다.
- 내일: 내일 마감 전체 일정을 숙제 우선 / 수행·시험·기타로 구분합니다. 전체 및 오늘의 내일 숙제와 동일한 원본 일정 ID를 공유합니다.
- 전체: 과거·오늘·미래 모든 일정을 날짜순으로 표시하고, 기존 월간 달력을 그대로 유지합니다.
- 진도: 기존 진도 등록, 상태 전환, 내보내기/가져오기, 진도 전체 복사, 완료율을 유지합니다.
- 오답: 기존 오답 기록과 복습일, 재풀이·숙달 조작, 수동 JSON 백업/복원을 유지합니다.
- 쓰기: 기존 영어 수행평가 문장 가리기·직접 입력·채점 연습 유지.
- 관리: 5개 학습 분류 역할, 삼성 리마인더 텍스트 복사, 상세정보 JSON 수동 백업·가져오기 및 진도·오답 바로가기.
- 탭은 화면 회전 시 복원하고, 개별 기능에서 편집/완료 체크 후 플래너에 돌아올 때 선택된 화면을 유지합니다.

## 데이터 안전
- 동일한 기존 Storage, StudyDailyChecklist, StudyProgressStorage, StudyWrongAnswers를 이용합니다. 보기만 바꾸므로 일정 자동 이동·중복 생성·자동 삭제·날짜 변경을 하지 않습니다.
- 미리 하기에서 마감일 변경 없이 원래 일정의 완료 상태만 체크합니다.
- Android debug test ID com.studyone.app.canary3, build 30103로 기존 Beta 및 이전 Canary와 별도 설치됩니다. 자동 데이터 이전은 없습니다. 이전 Canary를 삭제하기 전에 해당 앱의 필요한 데이터를 개별 JSON으로 백업하세요.
- iOS와 Windows 디자인은 이번 Android 전용 PR에서 수정하지 않았습니다.
