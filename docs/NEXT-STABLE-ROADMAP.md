## 0. 현재 기준선 (검증된 사실과 미검증 범위)

- 현재 공개 GitHub 릴리즈 최신: **v3.0.0-beta.2** (Android APK / iOS **unsigned** IPA, Stable 아님).
- 현 소스: Android Java 네이티브(`com.studyone.app`), iOS SwiftUI 네이티브(`com.studyone.ios`); Windows 데스크톱 앱/설치 파일은 아직 없음.
- NEIS 연동, 과제·시험 관리, 로컬 우선순위, 개인 OpenAI API 키 기반 AI, 로컬 JSON schema 1 백업이 구현되었다고 현행 릴리즈 문서에 명시되어 있음.
- **미구현/미검증**: 클라우드 계정·기기 간 실시간 동기화, ChatGPT 대화의 앱 데이터 읽기/쓰기, Windows EXE, iOS 실기기 설치·전체 기능 E2E. 과거 Android CI 성공은 새 버전의 기능 품질 보증을 의미하지 않음.
- 기존 Android 패키지명/서명 인증서, iOS 번들 ID, 기존 사용자 데이터, 공개 베타 태그·릴리즈 파일은 보존 대상.

## 1. 제품 목표와 범위

**StudyOne을 학습 기록의 단일 기준 저장소(source of truth)로 사용하며 Android·iOS·Windows에서 안정적으로 동일한 계획을 관리한다.** 사용자 편집을 우선하고 AI의 계획 제안·쓰기 결과는 검증과 이력으로 추적한다.

- **학습 데이터**: 과목/교재, 시험(일정·범위), 소단원, 완료·진행 중·미완료, 수행평가, 학교·학원·자기주도 숙제, 학습지·개념 정독, 시험범위 전체 오답 복습, 미완료 이월 사유.
- **5개 분류**: 개별 항목(전날 못 다), 정리 및 복습, 수행 및 암기, 숙제, 기타. 각 분류의 **영구 역할 설명**과 매일 바뀌는 실제 과제 목록은 서로 다른 필드로 저장.
- **플래너 정책**: 같은 날짜 '할꺼' 재생성 시 기존 계획을 함부로 축소·삭제하지 않음; 명시 변경/완료 보고만 반영; 비슷한 학습지 정리만 신중히 묶고 서로 다른 수행평가는 분리; 진도 진행은 '숙제', 전체 오답·학습지 정독은 '정리 및 복습'; 말하기 금지 학습 장소에서 구두 암기 제안 금지.
- **양방향 연동**: 앱에서 수정한 항목을 ChatGPT가 '변경사항 인지해'로 조회, ChatGPT의 '할꺼' 결과를 인증된 연결을 통해 앱에 저장. 연결 없는 일반 ChatGPT 대화 또는 OpenAI API 호출만으로 동기화된다고 주장하지 않음.
- **사용 경험**: 모바일/데스크톱 각각 자연스러운 UI, 접근성, 다크 모드, 키보드 단축키, 분류별 빠른 필터, 학습 기록 시각화, 오프라인 우선 및 충돌 회복.
- **성능**: 초기 구동 속도, 과제 목록 렌더링, 메모리, 배터리, 네트워크 사용량을 실제 장치에서 측정하고 개선.

## 3. Stable의 필수 수용 기준

1. Android 기존 고정 서명 설치본에서 안전한 업그레이드, 앱 데이터 보존 및 되돌리기 수단이 검증된다.
2. iOS는 서명/배포 경로가 실제 사용 가능하며 테스트 장치에서 설치·앱 데이터 보존이 검증된다. **unsigned IPA 단독으로 설치 가능하다고 주장하지 않는다.**
3. Windows는 **실제 설치 가능한 서명 정책이 명확한 EXE/MSIX**가 빌드되고, 설치·업데이트·제거 및 데이터 경로가 검증된다.
4. 세 플랫폼의 주요 기능 지원 범위는 동일 기준으로 문서화되고, 기능 차이는 릴리즈 전에 명확히 고지한다.
5. 사용자 기록을 자동으로 덮어쓰지 않으며, 충돌·오프라인·중복 전송·재시도·버전 불일치에 안전하다.
6. ChatGPT 연결의 도구 읽기·쓰기 권한은 분리된다. 수정/삭제는 사용자 인증·인가 및 필요한 승인 절차를 거친다.
7. API 비밀키는 공개 저장소, 앱 번들, 로그, 백업에 포함되지 않는다. 앱 사용자의 데이터는 최소 수집·전송한다.
8. NEIS·AI의 네트워크 장애에도 기본 오프라인 학습 관리가 사용 가능하다. API 호출 비용과 개인정보 처리 범위는 투명하게 표시한다.
9. 마이그레이션 성공·실패·취소 후 데이터 정합성과 복구 가능성을 검사한다.
10. CI 성공뿐 아니라 실기기/실환경 검증 증빙, 회귀·성능·접근성 점검, 서명/체크섬 확인을 기록한다.
