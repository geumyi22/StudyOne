# StudyOne v4 — Android/iOS 시험지 자동 분배 미리보기 UI

개발 브랜치: `feature/studyone-v4-integrated-release-candidate` (Draft PR #60). 이 변경은 공개 Beta/Stable 출시가 아니며, 기존 학습 원본을 자동 변경하지 않는다.

## 구현

- **Android:** 학습 플래너 > 진도, 그리고 공부 추천 화면에 `국어 인쇄 시험지 18회` 미리보기 버튼 추가.
- **iOS:** 교재·진도 화면에 같은 미리보기 시트를 추가.
- 시작일, 마감일, 하루 최대 회차(1~12), 첫 복습 출처(학습지/교재), 쉬는 날짜, 6종의 시험지별 총/완료 횟수를 사용자가 직접 입력한다.
- 계산기는 로컬 전용이다. 서버, OpenAI API, 계정 인증, 자동 동기화, 앱 저장소를 사용하지 않는다.
- 각 단원 내에서 시험지 유형을 순환하고 2·3단원을 균형 있게 배정한다. 완료한 회차는 다시 배정하지 않는다.
- 매 작업일 학습지·교재 복습 출처를 교대한다. 쉬는 날은 작업일에 포함하지 않는다.
- 마감일까지 처리할 수 없는 경우 미완성 계획을 내놓지 않고 명확히 거부한다.
- 결과는 날짜·단원·회차가 포함된 텍스트로 표시하며 사용자가 복사할 수 있다.
- 예시 기본값은 6종 × 3회 = 18회, 완료는 **전부 0회**다. 개인 기록에서 완료 횟수를 자동 가져오지 않으므로 사용자가 4/18회 완료 상태를 직접 입력해야 한다.
- UI는 **국어 2·3단원 고정 템플릿**이다. 모든 과목을 다루는 범용 편집기나 기존 Task 생성 기능은 아직 아니다.

## 안전 원칙

- 미리보기 계산에는 사용자 학습 기록의 읽기/쓰기, 데이터베이스 저장, 클라우드/ChatGPT 전송이 없다.
- 미리보기 복사는 사용자가 별도로 계획을 검토할 수 있게 돕는 기능이다. 숙제·진도 저장 승인으로 처리하지 않는다.
- 기존 완료 항목을 덮어쓰지 않는다. 같은 회차가 앱에 이미 있더라도 자동 합치거나 삭제하지 않는다.
- 계획의 원본 날짜 및 완료 기록은 사용자가 직접 확인해야 한다.

## 검증

- Android pure-Java: `scripts/tests/StudyPaperScheduleSmoke.java` (6종 18회/9일, 완료 회차 제외, 쉬는 날, 일일 상한, 입력 검증, 원본 불변).
- Android Planner Contract CI에서 Java 소스와 별도 회귀 테스트를 컴파일·실행한다. 실제 Android APK 빌드 및 에뮬레이터 실행도 별도.
- iOS: `StudyPaperSchedule.selfTest()`을 DEBUG 시뮬레이터 4종 백업/복구 E2E의 시작 단계에서 실행한다.
- 서버: 기존 `studyone_preview_paper_schedule` MCP 모형과 같은 날짜/분량/교대 규칙을 목표로 한다. 서버 기능 자체도 미리보기 전용이며, 앱의 로컬 미리보기는 **현재 서버 호출 없이 독립 실행**한다.
- 최종 SHA의 CI 성공을 확인하기 전에는 작동 완료라고 선언하지 않는다.

## 후속 개발

1. 임의 과목/단원 템플릿 편집 및 진도 회차별 안정적 ID 연결.
2. 사용자 최신 진도 불러오기 (같은 기기 원본의 검증된 스냅샷만 사용).
3. 미리보기 검토 → 중복 확인 → **사용자 승인** → 실제 할 일 등록을 별도 안전 기능으로 구현.
4. 별도의 운영 HTTPS/OAuth/MCP 인가 및 ChatGPT 앱 연결.
